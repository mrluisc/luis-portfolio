# COETAIL import data

`missing-posts.json` holds the 11 COETAIL posts (Feb to Nov 2020) that are not yet on mrluisc.com/blog, taken from
the 26 May 2021 WordPress export of lmoreno.coetail.com on 27 Oct 2026. Only each post's title, date, slug, word
count and body are here: no comments, no commenters, no email addresses.

Prepared before import, because this repo is public:
- every image is a placeholder, `[image: <file name>]` (52 in all). The surviving image files are in Luis Carlos's
  Google Drive, `COETAIL/Blog images (WD Passport)/`; he decides which go back.
- three links were removed and marked `[link removed before import: ...]`: a Flipgrid grid of responses, a shared
  Google Doc and a meeting recording.

Nothing here is on the site. A post goes up only after Luis Carlos reads it and says yes.
